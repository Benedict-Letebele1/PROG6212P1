System Overview
RaceDay is a comprehensive event management platform designed for South Africa's road running, walking, and cycling community. The system enables Event Organisers to create and manage events while allowing Participants to browse, register, and track their performance.
Organisers can create events, manage categories, view enrolments, and capture results.
Participants can browse events, enrol, view their enrolments, and track their results.
